Adaptive Clustering With Similarity Learning for Enhanced Multi-Scenario Radar Signal Processing

Sun, Qi, Cao, Zhen, Huang, Yulei, Ge, Yifan, Wang, Yunlong

3 分钟读懂

用自适应聚类生成伪标签，再用相似性学习判断簇间关系，提升复杂场景雷达信号分选鲁棒性。

核心结论

雷达信号分选可以先用聚类形成弱标签，再用相似性网络修正簇级关系，从而降低标注依赖。

方法概览

ACSL 先在 RF、PW、DOA 等特征空间中进行动态分区与自适应缩放，生成并优化伪标签；随后用双分支相似性学习网络结合 PRI 与特征差异判断不同簇是否来自同一雷达。

为什么重要

这套流程把无监督聚类、PRI 信息和深度相似性判别组合起来，更贴近真实电子侦察中标签稀缺和场景变化的问题。

核心结论

雷达信号分选可以先用聚类形成弱标签，再用相似性网络修正簇级关系，从而降低标注依赖。

研究问题

雷达信号分选在高密度、强交织和多场景数据分布变化下容易退化，完全监督深度模型又依赖大量标注数据。

方法概览

ACSL 先在 RF、PW、DOA 等特征空间中进行动态分区与自适应缩放，生成并优化伪标签；随后用双分支相似性学习网络结合 PRI 与特征差异判断不同簇是否来自同一雷达。

技术路线

01

Feature partition

按 RF、PW、DOA 对 PDW 流进行动态分区。

02

Pseudo labels

通过自适应聚类和缩放因子生成初始簇。

03

PRI relation

计算簇间 PRI 与特征差异。

04

Similarity network

判断簇是否应合并为同一雷达源。

证据与结果

监督需求 Pseudo-label

减少对大规模标注数据的依赖。

鲁棒性 Multi-scenario

关注跨场景分布变化下的分选效果。

任务输出 RSS clusters

输出雷达脉冲分选后的簇关系。

主要贡献
  • 用自适应缩放因子降低不同场景和子块间数据分布差异。
  • 将伪标签优化与 similarity learning 结合，减少对大规模标注数据的依赖。
  • 面向电子侦察中的 RSS 任务，兼顾分选准确率、纯度、鲁棒性与计算时间。
