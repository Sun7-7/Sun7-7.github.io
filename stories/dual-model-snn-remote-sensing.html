双模型互蒸馏与遥感图像分类

Dual-model spiking neural network for remote sensing image classification using mutual knowledge distillation

Zhen Cao, Ju Liu, Qi Sun, Biao Hou, Hao Zhu, Lei Guo, Yifan Ge, Yulong Wang, and Licheng Jiao.

Neurocomputing, 651, 130721 (2025)

阅读 PDF

研究问题

遥感图像分类对边缘端低功耗和实时性要求很高，但 SNN 往往需要较长时间步才能保持充分信息表达，短时间步会带来精度下降。

核心方法

Long-Short Step Dual-Model Mutual Distillation 让长步模型与短步模型协同训练并相互蒸馏，同时用平滑随机时间步机制逐步降低短步模型时间步，减轻低延迟训练的信息损失。

方法步骤
  1. Long-step SNN

    保持更充分的时序信息表达。

  2. Short-step SNN

    面向低延迟推理约束。

  3. Mutual distillation

    长短模型在训练中共享知识和判别信息。

  4. Smooth timestep

    平滑降低短步模型时间步，避免训练突变。

代表性发现

低延迟 SNN 不应孤立训练，短时间步模型可以通过长时间步模型的知识迁移保持信息表达。

科学意义

遥感边缘部署需要同时考虑能耗、延迟和精度，该框架给出了降低 SNN 时间步时保持性能的一种训练策略。

科研图

适用条件

可把这篇论文作为 SNN 低延迟训练的案例：不是只改网络结构，而是通过训练机制降低时间步依赖。
